# §1.1 感悟：目标 vs 训练手段

## 我的原话
> "agent 的目标不是这一步奖励最大，而是整条轨迹累计奖励最大。这是 RL 与一切贪心方法的根本分水岭。"——但其实在实际的训练中，有时候也并不是按照整条轨迹去训练的。

## 修正与补充

✓ **完全正确，而且抓到了一个教材没明说的关键区分**：**目标 (objective)** 与 **训练手段 (estimator)** 是两件事。

| | 概念 | 实现 |
|---|---|---|
| 目标 | 最大化 $J(\pi) = \mathbb{E}\big[\sum_t \gamma^t r_t\big]$ | — |
| 训练手段 | — | MC / TD(0) / n-step / GRPO 单步 / PPO ... 多种估计器 |

教材原文在讲"agent 想要什么"，不是"工程必须按轨迹算梯度"。

### 补充三点

**① 同一个目标，多种估计器**
- MC（Ch 5）：真跑完整轨迹算 $G_t = \sum_t \gamma^t r_t$
- TD(0)（Ch 6）：用 $r + \gamma V(s')$ 单步自举近似 $G_t$
- n-step（Ch 7）：折中，先实跑 n 步再用 V 兜底
- 单步 GRPO + bootstrap：把 $r$ 替换成 $r + \gamma V$ 后，单步训练 ≠ 单步目标——它在估计长期目标，只是用了更便宜的估计器

**② 单步 GRPO 不是"放弃长期目标"，而是"换了估计器"**
- 把整条轨迹的优化降为若干独立 contextual bandit 子问题
- 是估计器层面的简化，不是目标改了
- 如果 r_t 设计本身已反映长期价值（如含未来 N 分钟预测），单步训练仍能学到长期最优

**③ TD 学习的精神**：**长期目标 + 短期信号 + 自举**。这是后续 Ch 5→6→7→12 的核心张力。

## 修正后的版本（建议内化）
> RL 的**目标**永远是轨迹累计奖励 $J(\pi) = \mathbb{E}[\sum \gamma^t r_t]$；但**优化这个目标的手段**可以是 MC、TD、bootstrap、单步等多种估计器。"是否按整条轨迹训练"是工程选择，不改变目标本身。

# §1.1 感悟二：RL 是第三种范式，不是无监督学习的子集

## 我的原话
> "RL 不是无监督学习的一种，RL 是与监督和无监督学习并列的第三种范式。"

## 修正与补充

✓ **完全正确**。这是教材在 §1.1 第 2 段就明确反驳的常见误解。

### 为什么容易被误归为无监督

| 表面相似点 | 真实差异 |
|---|---|
| 都不需要人工 label | 无监督的"无 label"指无目标信号；RL 有 reward，只是 reward ≠ label |
| 都从原始数据中学 | 无监督的数据是**给定**的；RL 的数据是 agent **自己产生**的（分布随 π 变） |
| 都被称为"自学习" | 学的东西不同：无监督学结构，RL 学最大化 reward 的策略 |

### 划清三者边界的判别式

问三件事就能定性：
1. **每条数据有没有 reward / label / 都没有？** → 有 label 是 SL，有 reward 是 RL，都没是 UL。
2. **数据分布会不会随模型而变？** → 只有 RL 会（非平稳数据是 RL 独有难点）。
3. **反馈是指令式还是评价式？** → 指令式 = SL，评价式 = RL，无 = UL。

### 一个常见混淆要小心
- **自监督学习 (self-supervised)** 也常被说成"不要 label"，但它属于 SL 的一种伪装——label 是从数据里**自动构造**的（如 masked token、对比学习正负样本），反馈仍是指令式。它不是 RL，也不是经典 UL。

## 修正后的版本（建议内化）
> 机器学习三大范式按**反馈类型**分：
> - SL = 指令式反馈（有正确答案）
> - UL = 无反馈（找结构）
> - RL = 评价式反馈（只打分） + 序贯决策 + 数据由策略产生
>
> 三者**并列**，不是包含关系。"无 label" 不是 UL 的充要条件。

# §1.1 感悟三：10 个老虎机——只利用不探索 = 把噪声当真理

## 触发题（Q2）
> agent 玩 10 个老虎机，前 100 步只拉它觉得最好的那一台，会怎样？

## 我的感悟
> 这题点醒了我："只利用"不是单纯"贪心"那么简单——它是**把早期小样本估计直接当真值用**。前几次拉某台运气好 → 估计虚高 → 之后一直拉它 → 永远没机会发现真正最优的那台。最优臂可能从一开始就被几个差样本"冤枉"了，永远翻不了身。

## 修正与补充

✓ **抓到核心了**。这正是 Sutton 在 Ch 2 反复强调的 **action-value 估计的方差问题**。

### 把直觉量化一下

设真实期望 $q_*(a)$ 未知，agent 用样本均值 $Q_t(a) = \frac{1}{N_t(a)}\sum r$ 估计。
- 前几次拉一台，$N_t(a)$ 极小，$Q_t(a)$ 方差 $\propto 1/N_t(a)$，**估计噪声压倒真实差异**。
- 纯贪心策略 $A_t = \arg\max_a Q_t(a)$ 一旦认定一台，$N_t$ 只在那台增长，其他臂的 $Q$ 永远停在初始噪声值。
- 结果：**收敛到某个臂**，但**不一定是最优臂**——这是 *suboptimal lock-in*。

### 三个推论（值得记住）

**① 这不是"运气问题"，是结构性缺陷**
- 即使把实验重复 10000 次，纯贪心的**期望最终收益**仍严格低于带探索的策略。这是可以解析证明的（Ch 2 习题）。

**② 解决方案的本质：给"未充分采样的臂"加权**
- ε-greedy：硬性强制 ε 比例随机探索 → 简单但浪费
- 乐观初始化（optimistic init）：把 $Q_0$ 设得很高，逼 agent 把每台都试够 → 巧妙但只在平稳问题下管用
- UCB：按 $Q_t(a) + c\sqrt{\ln t / N_t(a)}$ 选 → 把"采样不足的不确定性"显式当作奖励加成
- Thompson Sampling：维护后验分布按概率采样 → 贝叶斯视角下最自然
- 共同点：**所有方法都在补偿"小样本臂"的信息缺失**，而不是补偿"奖励低的臂"。

**③ 跟我做的 LLM-RL 交通控制项目直接相关**
- 单步 GRPO 同样是 contextual bandit 的多臂问题。
- 如果某个 (state, action) 组合早期采样少 + 偶然 reward 低 → policy gradient 会迅速把它的概率压到 ~0 → 之后再也采不到 → **策略坍缩到次优 mode**。
- 这就是 entropy bonus / KL 正则 / 温度采样存在的原因——它们在做和 ε-greedy 同质的事：**强行给低概率动作留出采样机会**。

## 一句话总结（建议内化）
> 纯利用 = 信任小样本估计 = 把早期噪声当真理。
> 探索的本质不是"随机一下"，而是**为采样不足的选项保留信息收集预算**——这条原则从 bandit 一路贯穿到 LLM-RL。
