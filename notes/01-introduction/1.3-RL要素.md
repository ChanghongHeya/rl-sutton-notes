# §1.3 强化学习的要素 (Elements of Reinforcement Learning) ★

> 来源：Sutton & Barto《强化学习导论》第 2 版，印刷 p.6-7 / PDF 28-29
> **本节地位**：★ 面试必背。引入 RL 的 4 个核心要素，是后面所有章节的"零件清单"。

---

## 总览

> Beyond the agent and the environment, one can identify **four main subelements of a reinforcement learning system**: a **policy**, a **reward signal**, a **value function**, and, optionally, a **model** of the environment.

**中译**：除了 agent 和 environment 之外，强化学习系统可识别出**四个主要子元素**：**策略 (policy)**、**奖励信号 (reward signal)**、**价值函数 (value function)**，以及可选的**环境模型 (model)**。

**讲解**：
- 教材把 RL 系统拆成 **5+1** 层：(agent, environment) 是外壳，**policy / reward / value / model** 是内核。
- 前三个**几乎所有 RL 算法都有**；model 是 model-based 方法独有，model-free 方法（Q-learning、Sarsa、REINFORCE）不需要。
- **背诵句**："策略选动作，奖励定目标，价值看长远，模型可有可无。"

---

## 1. Policy（策略）★★

### 原文
> A **policy** defines the learning agent's way of behaving at a given time. Roughly speaking, a policy is a mapping from perceived states of the environment to actions to be taken when in those states. ... In some cases the policy may be a simple function or lookup table, whereas in others it may involve extensive computation such as a search process. The policy is the core of a reinforcement learning agent in the sense that it alone is sufficient to determine behavior. In general, policies may be **stochastic**, specifying probabilities for each action.

### 中译
策略定义了 agent 在给定时刻的**行为方式**。粗略地说，策略是从感知到的环境状态到在该状态下要采取的动作的一种**映射**。在某些情况下策略可以是简单函数或查找表，在另一些情况下则可能涉及大量计算（如搜索过程）。策略是 RL agent 的**核心**——单凭策略就足以决定行为。一般而言策略可以是**随机的**，给出每个动作的概率。

### 讲解

**数学形式**：
$$
\pi(a \mid s) = \Pr(A_t = a \mid S_t = s)
$$
读作"在状态 $s$ 下选动作 $a$ 的概率"。

**两种类型**：
| 类型 | 形式 | 例子 |
|---|---|---|
| 确定性 (deterministic) | $a = \pi(s)$ | "看见红灯就停" |
| 随机性 (stochastic) | $\pi(a\mid s)$ 是概率分布 | ε-greedy、softmax 策略、LLM 采样 |

**为什么要随机策略？**
1. **探索需要**：纯 deterministic 在 §1.1 老虎机题里会卡死在次优。
2. **博弈/部分可观测**：剪刀石头布、扑克这类对手会预测你 → 必须随机。
3. **理论便利**：策略梯度方法（REINFORCE / PPO / GRPO）需要 $\pi$ 可微 → 必须 stochastic 才有梯度。

**实现方式光谱**（从简单到复杂）：
- 查找表：状态空间小（井字棋、网格世界）
- 线性函数：$\pi_\theta(a\mid s) \propto \exp(\theta^\top \phi(s,a))$（softmax）
- 神经网络：DQN 的 ε-greedy over Q-net，PPO 的 actor 网络，**LLM 本身就是个 $\pi(a\mid s)$**（s = prompt + history，a = next token）
- 搜索过程：MCTS（AlphaGo），policy = 树搜索的访问统计

**面试口径**：策略是"agent 大脑里的决策函数"——单看 $\pi$ 就能决定 agent 怎么行动，其他三件（reward / value / model）都是为了**改进** $\pi$ 而存在。

## 2. Reward Signal（奖励信号）★★

### 原文
> A **reward signal** defines the goal of a reinforcement learning problem. On each time step, the environment sends to the reinforcement learning agent a single number called the **reward**. The agent's sole objective is to maximize the total reward it receives over the long run. The reward signal thus defines what are the good and bad events for the agent. ... The reward signal is the primary basis for altering the policy; if an action selected by the policy is followed by low reward, then the policy may be changed to select some other action in that situation in the future. In general, reward signals may be stochastic functions of the state of the environment and the actions taken.

### 中译
奖励信号**定义了 RL 问题的目标**。在每个时间步，环境向 agent 发送一个**标量**数值，称为奖励 (reward)。agent 的**唯一目标**是最大化长期累积奖励。奖励信号因此**定义了哪些事件是好的、哪些是坏的**。奖励信号是改变策略的**首要依据**：如果某个动作之后跟着低奖励，那么未来在该情境下策略可能会被改成选其他动作。一般而言奖励可以是状态和动作的**随机**函数。

### 讲解

**关键三点**：

**① 标量 (scalar)**：$R_t \in \mathbb{R}$，**只能是一个数**。
- 如果你的目标是多目标（速度+能耗+安全），必须**手工合成**为一个数：$R = w_1 \cdot \text{speed} - w_2 \cdot \text{energy} - w_3 \cdot \text{collision}$
- 这个权重选取本身就是个工程问题——叫 **reward shaping**，第 17 章会重点讲。
- 你的 LLM-RL 交通控制项目里的"通行效率 reward"就是个典型多目标合成。

**② Reward 来自环境，不是 agent**：
- agent 不能"自己定义自己开心"——这会让目标失控。
- reward function 由设计者写死在环境里。
- 这条在 §3.2 会再强调，是避免 reward hacking 的根本约束。

**③ Reward 定义了 "what"，不是 "how"**：
- reward 只说"赢棋 = +1"，不说"该走车还是走马"。
- "怎么走"是 policy 的事，"想去哪"是 reward 的事。**两者绝不能混**。

**常见误区**（面试陷阱）：
- ✗ "agent 的目标是最大化即时 reward" → 应是**长期累积** reward。
- ✗ "agent 学会让 reward 变大" → agent 只能改变 policy 来**间接**让 reward 变大；reward 函数本身不可学（meta-RL 除外）。

## 3. Value Function（价值函数）★★★

### 原文
> Whereas the reward signal indicates what is good in an **immediate** sense, a **value function** specifies what is good in the **long run**. Roughly speaking, the **value of a state** is the total amount of reward an agent can expect to accumulate over the future, starting from that state. Whereas rewards determine the immediate, intrinsic desirability of environmental states, values indicate the long-term desirability of states after taking into account the states that are likely to follow and the rewards available in those states. ... Rewards are in a sense primary, whereas values, as predictions of rewards, are secondary. Without rewards there could be no values, and the only purpose of estimating values is to achieve more reward. Nevertheless, **it is values with which we are most concerned when making and evaluating decisions**. ... Unfortunately, it is much harder to determine values than it is to determine rewards. ... Indeed, the most important component of almost all reinforcement learning algorithms we consider is a **method for efficiently estimating values**.

### 中译
奖励信号衡量的是**即时**的好坏；而**价值函数**衡量的是**长期**的好坏。粗略地说，**一个状态的价值** = 从该状态出发，agent 未来期望能累积到的**总奖励**。reward 决定了状态的即时内在优劣，value 则在考虑了"接下来会到哪些状态、那些状态能拿什么 reward"之后，给出**长期**优劣判断。

reward 在某种意义上是**第一性**的，而 value 是 reward 的**预测**，是**第二性**的。没有 reward 就没有 value，估计 value 的唯一目的就是拿到更多 reward。**然而我们在做决策和评估决策时，最关心的反而是 value**。可惜的是，**估计 value 远比测量 reward 困难**。事实上，几乎所有 RL 算法最重要的组成部分，都是**高效估计价值的方法**。

### 讲解

**两种价值函数（Ch 3 详讲，先记下）**：

**① 状态价值 $v_\pi(s)$**：从状态 $s$ 起、按策略 $\pi$ 行动，能拿到的期望累积奖励。
$$
v_\pi(s) = \mathbb{E}_\pi\Big[\sum_{k=0}^{\infty} \gamma^k R_{t+k+1} \,\Big|\, S_t = s\Big]
$$

**② 动作价值 $q_\pi(s,a)$**：在 $s$ 选 $a$、之后按 $\pi$ 行动的期望累积奖励。
$$
q_\pi(s,a) = \mathbb{E}_\pi\Big[\sum_{k=0}^{\infty} \gamma^k R_{t+k+1} \,\Big|\, S_t = s, A_t = a\Big]
$$

**为什么 value 比 reward 难估？**
- reward 是当下事实（环境直接告诉你 $R_{t+1}$）。
- value 是"对未来的期望"——必须**预测**。
- 而且 value 是关于 $\pi$ 的，$\pi$ 一变 value 就变 → **非平稳估计目标**。

**为什么决策时最关心 value 而不是 reward？**
- 例子：当前 reward = -1，但能进一个高 value 状态（先苦后甜）→ 该选。
- 完全反过来：当前 reward = +10，但进入死胡同（低 value）→ 不该选。
- → **贪心 reward = 短视；贪心 value = 远见**。这也是 §1.1 "目标 vs 估计器"心得里讲的事。

**RL 的本质口号**：
> **几乎所有 RL 算法的核心，就是"如何高效估计 $v$ 或 $q$"**。
> - DP：用 Bellman 方程递推 →（已知模型）
> - MC：跑完整 episode 平均 → 无偏但方差大
> - TD：用 $r + \gamma V(s')$ 自举 → 有偏但方差小
> - 函数逼近：$v_\theta(s)$ 用神经网络拟合 → 解决大状态空间
> - GRPO 里的 group baseline：也是在估 advantage（$q - v$ 的近似）

→ **后面 90% 的内容都在围着 value estimation 转**。

## 4. Model of the Environment（环境模型）— 可选

### 原文
> The fourth and final element of some reinforcement learning systems is a **model** of the environment. This is something that mimics the behavior of the environment, or more generally, that allows inferences to be made about how the environment will behave. For example, given a state and action, the model might predict the resultant next state and next reward. Models are used for **planning**, by which we mean any way of deciding on a course of action by considering possible future situations before they are actually experienced. Methods for solving reinforcement learning problems that use models and planning are called **model-based** methods, as opposed to simpler **model-free** methods that are explicitly trial-and-error learners — viewed as almost the opposite of planning.

### 中译
某些 RL 系统的第四个、也是最后一个要素是**环境模型**。它**模拟**环境的行为，或者说，它能让 agent 对"环境接下来会怎样"做推断。例如：给定 (state, action)，模型预测下一个 state 和 reward。模型用于**规划 (planning)**——所谓规划是指**在实际经历之前**通过考虑可能的未来情境来决定行动方案。使用模型和规划的 RL 方法称为 **model-based**，与之相对的是**纯试错**的更简单的 **model-free** 方法（几乎是规划的反面）。

### 讲解

**Model 形式上是两个函数**：
- 状态转移：$p(s' \mid s, a)$
- 奖励函数：$r(s, a)$ 或 $r(s, a, s')$

**有 vs 没有 model 的方法对比**（Ch 4-8 会反复出现）：

| 类别 | 代表算法 | 优点 | 缺点 |
|---|---|---|---|
| **Model-based** | 动态规划 (Ch4) / Dyna-Q (Ch8) / MCTS (Ch8) / AlphaZero | 样本效率高（可在 model 里反复 rollout） | 需要好的 model；model 错了会误导 |
| **Model-free** | MC / TD / Q-learning / Sarsa / REINFORCE / PPO / GRPO | 不依赖建模，直接从经验学 | 样本效率低，需要大量交互 |

**Planning vs Learning**：
- **Learning**：从**真实经验**中改进 policy/value
- **Planning**：从**模拟经验**（model 产生的）中改进 policy/value
- → Ch 8 "Dyna-Q" 把两者**合在同一个循环**里，是表格型 RL 的高峰。

**对你 LLM-RL 项目的启示**：
- 如果你能学一个"路况转移模型"（给定当前路况+信号灯方案 → 5 分钟后路况），就能在虚拟环境里 rollout，**大幅减少真实路网的试错代价**。
- 这是 model-based RL 在工业控制里的核心吸引力。

## 一句话总结（必背）

> RL 系统 = (agent + environment) + **policy（怎么做）** + **reward（要什么）** + **value（值不值）** + **model（环境怎么变，可选）**。
>
> - **reward 是第一性的**（定义目标），**value 是第二性的**（预测累积 reward）。
> - **几乎所有 RL 算法的核心，都是"如何高效估计 value"**。
> - **有没有 model**把方法分成两大派：model-based（规划）vs model-free（试错）。

## 自测题与答案

### Q1（概念区分，面试高频）
**问**：reward 和 value 有什么区别？为什么我们做决策时更看重 value？

**答**：
- **reward** = 即时反馈，是环境直接给的标量 $R_{t+1}$。
- **value** = 长期期望累积 reward，$v_\pi(s) = \mathbb{E}_\pi[\sum \gamma^k R_{t+k+1}]$。
- reward 是"第一性"的（定义目标），value 是 reward 的"预测"。
- **决策更看 value 的原因**：贪心 reward 会短视——当前低 reward 但通向高价值状态的动作（先苦后甜）才是对的。象棋牺牲皇后换将军就是典型例子：当前 reward 极负，但 value 极高。

### Q2（policy 类型）
**问**：什么情况下我们必须用随机策略而不是确定性策略？

**答**：至少三种情况：
1. **需要探索**：纯确定性会卡死在初始估计的局部最优（§1.1 老虎机题）。
2. **博弈/部分可观测**：对手会预测你 → 必须随机化（剪刀石头布、扑克）。
3. **策略梯度方法**：$\nabla_\theta \log \pi_\theta(a\mid s)$ 要求 $\pi$ 是可微分布 → 必须随机。

### Q3（model-based vs model-free）
**问**：以下哪种属于 model-based RL？
A. Q-learning
B. REINFORCE
C. Dyna-Q
D. PPO

**答**：**C**。Dyna-Q 显式学一个环境模型 $\hat{p}(s'\mid s,a)$ 并在模型里做规划更新，是经典 model-based。A/B/D 都是 model-free，直接从交互轨迹学 value 或 policy。

### Q4（要素归属）
**问**：以下事物分别属于 4 要素中的哪一个？
1. ε-greedy 决策规则
2. 游戏的最终得分
3. 神经网络估计的 $V(s)$
4. AlphaGo 的蒙特卡洛树搜索使用的"假想下一步"

**答**：1=policy，2=reward，3=value function，4=model（树搜索内部模拟环境，本质是用 model 做 planning）。

## 关键词速查

- **policy** $\pi(a\mid s)$：状态→动作（概率）
- **reward signal** $R_t$：即时标量反馈，**定义目标**
- **value function** $v_\pi(s)$ / $q_\pi(s,a)$：长期期望累积 reward
- **model** $p(s'\mid s,a)$, $r(s,a)$：环境的可推断/可模拟版本
- **model-based vs model-free**：用不用 model 做 planning
- **planning vs learning**：从模拟经验 vs 真实经验改进策略
- **reward shaping**：把多目标合成单标量的工程艺术
