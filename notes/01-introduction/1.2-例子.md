# §1.2 例子 (Examples)

> 来源：Sutton & Barto《强化学习导论》第 2 版，印刷 p.4-5 / PDF 26-27
> **非重点节**：本节不引入新概念，只用 5 个例子让 §1.1 的抽象定义"落地"。读完能在头脑里把 RL 五要素套到任意场景即可。

---

## 1. 五个例子（速览）

| # | 场景 | state | action | reward | 关键特点 |
|---|---|---|---|---|---|
| 1 | **国际象棋大师**走子 | 棋盘局面 | 落子 | 胜/负/和 | 既靠规划（看几步），也靠对局面好坏的**直觉判断**（价值函数雏形） |
| 2 | **自适应控制器**调节石油精炼厂 | 工艺参数 | 调节阀门/流量 | 产量/质量/成本的折中 | **在线**实时调整，从历史指标里学，不依赖工程师设定的最优点 |
| 3 | **小羚羊**学走路 | 自身关节/平衡感知 | 蹬腿协调 | 站起来 / 不摔 | 出生半小时跑 20mph，**几乎纯试错**，强生物学动机 |
| 4 | **移动机器人**决定是否回去充电 | 电量 + 环境感知 | 继续工作 / 返回 | 完成的任务量 - 没电卡死的代价 | **基于过往经验**的权衡，没有解析最优解 |
| 5 | **Phil 准备早餐**（家务序贯决策） | 厨房当前状态 | 走 / 拿 / 倒 / 加热 | 吃上 / 吃好 | 看似日常，其实嵌套了**目标分解 + 子任务规划 + 动作执行**的全流程 |

---

## 2. 五个例子的共同特征（**这才是本节真正的 takeaway**）

教材在例子之后归纳了所有 RL 问题共有的**四个特征**——这是你后面遇到任何场景判断"这是不是 RL 问题"的检查清单：

1. **主动交互 (active interaction)**
   - agent 的动作**会改变环境**和未来收到的状态
   - 区别于监督学习：SL 的 (x, y) 是固定数据集，模型对 x 的预测不影响下次给什么 x。

2. **目标明确但环境不确定 (goal in face of uncertainty)**
   - 有清晰目标（赢棋 / 不摔 / 吃上早餐），但环境随机或部分未知。
   - 必须**边学边决策**，不能等知识完备再行动。

3. **当前动作影响未来 (delayed consequences)**
   - 走错一步现在可能没事，几步之后才暴露。
   - → 必须考虑**长期回报**而非即时奖励 → 这是 §1.1 "目标 = 累积奖励"的根源。

4. **从经验中学习 (learning from experience)**
   - 不是被告知"该这么做"，而是**做了之后**根据效果自我修正。
   - → 评价式反馈，是 §1.1 区分 SL/RL 的本质。

---

## 3. 一个值得注意的暗线：规划 vs 反应

教材在象棋例子里偷偷点了一下：**RL agent 既要会"前瞻规划"（向前展开几步），也要会"快速直觉"（不展开，直接靠学过的价值估计）**。这条线索后面会展开成：

- 第 4 章 **DP**：完全规划（已知模型）
- 第 5-7 章 **MC / TD**：纯经验学习（不规划）
- 第 8 章 **Dyna-Q / MCTS**：**学习 + 规划 + 反应** 三者融合 ★

→ 现在不用深究，但记住"小羚羊半小时学会跑"和"象棋大师看 30 步"是 RL 光谱的两端，第 8 章会把它们统一。

---

## 4. 一句话总结

> §1.2 没有新公式，只有一个判别式：
> **能交互 + 目标驱动 + 不确定 + 后果延迟 + 试错学习** → 这就是 RL 的味道。

## 自测题与答案

### Q1（套用判别式）
**问**：训练一个推荐系统，每天根据用户点击日志离线重训模型。这是 RL 吗？

**答**：**不是经典 RL**，是 SL（带有 RL 味道的退化情形）。
- ✓ 有"目标"（点击率最大化）
- ✗ 但模型**不直接交互**：日志是固定数据集，模型预测**不会立刻改变**接下来收到的样本
- ✗ 没有显式建模"这次推这个会影响下次推什么"
- → 真正的 RL 推荐（contextual bandit / RL ranking）才会显式建模"我推 A 给用户，下次他点击行为会变"。这条边界在 §2.9 关联搜索会再触及。

### Q2（找出非 RL 特征）
**问**：以下哪条**不是** RL 问题的必要特征？
A. agent 的动作影响未来观测
B. 反馈是评价式的（数值 reward）
C. 必须有显式的状态转移概率模型
D. 当前动作可能延迟影响最终结果

**答**：**C**。RL 不要求 agent 知道环境的转移概率——这正是 §1.1 提到的"**不完全已知** MDP"。Model-free 方法（MC / TD / Q-learning）整个就建立在"模型未知"之上。
