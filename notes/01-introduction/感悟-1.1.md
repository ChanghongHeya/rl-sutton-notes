# §1.1 感悟：目标 vs 训练手段

## 我的原话
> "agent 的目标不是这一步奖励最大，而是整条轨迹累计奖励最大。这是 RL 与一切贪心方法的根本分水岭。"——但其实在实际的训练中，有时候也并不是按照整条轨迹去训练的。

## 修正与补充

✓ **完全正确，而且抓到了一个教材没明说的关键区分**：**目标 (objective)** 与 **训练手段 (estimator)** 是两件事。

| | 概念 | 实现 |
|---|---|---|
| 目标 | 最大化 $J(\pi) = \mathbb{E}\big[\sum_t \gamma^t r_t\big]$ | — |
| 训练手段 | — | MC / TD(0) / n-step / GRPO 单步 / PPO ... 多种估计器 |

教材原文在讲"agent 想要什么"，不是"工程必须按轨迹算梯度"。

### 补充三点

**① 同一个目标，多种估计器**
- MC（Ch 5）：真跑完整轨迹算 $G_t = \sum_t \gamma^t r_t$
- TD(0)（Ch 6）：用 $r + \gamma V(s')$ 单步自举近似 $G_t$
- n-step（Ch 7）：折中，先实跑 n 步再用 V 兜底
- 单步 GRPO + bootstrap：把 $r$ 替换成 $r + \gamma V$ 后，单步训练 ≠ 单步目标——它在估计长期目标，只是用了更便宜的估计器

**② 单步 GRPO 不是"放弃长期目标"，而是"换了估计器"**
- 把整条轨迹的优化降为若干独立 contextual bandit 子问题
- 是估计器层面的简化，不是目标改了
- 如果 r_t 设计本身已反映长期价值（如含未来 N 分钟预测），单步训练仍能学到长期最优

**③ TD 学习的精神**：**长期目标 + 短期信号 + 自举**。这是后续 Ch 5→6→7→12 的核心张力。

## 修正后的版本（建议内化）
> RL 的**目标**永远是轨迹累计奖励 $J(\pi) = \mathbb{E}[\sum \gamma^t r_t]$；但**优化这个目标的手段**可以是 MC、TD、bootstrap、单步等多种估计器。"是否按整条轨迹训练"是工程选择，不改变目标本身。
