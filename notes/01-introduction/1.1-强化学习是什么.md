# §1.1 什么是强化学习 (Reinforcement Learning)

> 来源：Sutton & Barto《强化学习导论》第 2 版，印刷 p.1-4 / PDF 23-26

## 一句话定义

**强化学习 = 一个 agent（智能体）通过和环境反复互动，从"行动→反馈"中学会怎样做才能让长期累积奖励最大化。**

它不是被告诉"正确答案是什么"，而是被告诉"你刚才那一下做得多好（一个数值）"，然后自己摸索。

---

## 1. 核心场景：agent ↔ environment 闭环

```
        action At
   ┌──────────────►┐
agent              environment
   ◄──────────────┘
   reward Rt+1, state St+1
```

每一步循环：
1. agent 观察当前状态 `St`
2. 选一个动作 `At`
3. 环境返回奖励 `Rt+1` 和新状态 `St+1`
4. 回到第 1 步

agent 的目标不是"这一步奖励最大"，而是**整条轨迹累计奖励最大**。这是 RL 与一切贪心方法的根本分水岭。

---

## 2. RL 与监督学习 / 无监督学习的区别（★面试高频）

| | 监督学习 | 无监督学习 | 强化学习 |
|---|---|---|---|
| 数据 | (x, **正确 label**) | 只有 x | (s, a, **r**, s′) 序列 |
| 反馈 | **指令式 (instructive)**：告诉你正确答案 | 无反馈 | **评价式 (evaluative)**：只告诉你"你这一下好坏"，不告诉你最优是什么 |
| 数据来源 | 数据集（i.i.d.） | 数据集 | **agent 自己交互产生**，分布会随策略改变 |
| 关心啥 | 泛化到新样本 | 发现结构 | 最大化累积 reward |

**关键区别**：
- 监督学习：有老师，老师说"这张图是猫"。
- RL：没老师，环境只给你打分。你下了一步臭棋，环境扣 5 分，但**不会告诉你正确该怎么走**。
- 这就是为什么 RL 必须**主动尝试**——否则你永远不知道有没有更好的选择。

> ⚠️ 容易混淆：**RL 不是无监督学习的一种**。无监督学习是找数据中的隐藏结构；RL 是最大化奖励信号。两者目标完全不同。RL 是与监督/无监督**并列**的第三种范式。

---

## 3. 探索 vs 利用 (exploration vs exploitation) ★★

这是 RL **独有**的核心难题，监督/无监督学习里根本不存在。

- **利用 (exploit)**：选目前已知最好的动作，立刻拿奖励。
- **探索 (explore)**：试还没试过/试得少的动作，看看是不是更好。

矛盾在于：**一次只能选一个动作**——你利用了就没探索，探索了就没利用。
- 全利用 → 可能永远困在次优策略里。
- 全探索 → 永远学不到，每次都在乱试。

**直觉例子**：你常去的那家餐厅 8 分（利用）；隔壁新开一家可能 10 分也可能 4 分（探索）。下次吃哪家？

> 这个矛盾几十年的数学研究至今**没有完全闭合解**。后续 Ch 2 会讲 ε-greedy、UCB、Thompson Sampling 等几种实用平衡方法。

---

## 4. RL 与控制论 / MDP 的关系（先有个印象，Ch 3 详讲）

数学上，RL 把问题形式化为 **不完全已知的 Markov 决策过程 (MDP) 的最优控制**。
MDP 抓住三件事：**感知 (state) + 行动 (action) + 目标 (reward)**。
"不完全已知"指 agent 不知道环境的转移概率和奖励函数，必须从交互中学。

---

## 5. RL 的三个气质（区别其他 AI 方法）

1. **整体性 (whole problem)**：不是孤立解决"识别"或"规划"，而是把"感知 + 决策 + 学习"放在一个完整 agent 里端到端解决。
2. **不确定性是默认假设**：环境随机、模型未知，从一开始就要面对。
3. **回归通用原则**：不靠堆专家规则，靠通用的搜索 + 学习原理。

---

## 6. 一句话总结（背下来）

> **强化学习 = 评价式反馈 + 序贯决策 + 探索/利用权衡**，目标是最大化期望累积奖励。

## 自测题与答案

### Q1（概念区分）
**问**：训练一个模型识别 X 光片里有没有肿瘤。这是 RL 还是监督学习？训练一个机器人在医院里送药呢？

**答**：
- 肿瘤识别 = **监督学习**。每张片子有专家标注的"有/无肿瘤"标签，反馈是指令式的，且数据是固定数据集。
- 机器人送药 = **强化学习**。没人能预先标注"在每个走廊每个时刻该往哪走"；机器人需要根据当前位置选动作（前进/转向/避让），环境根据是否撞人、是否准时送达给数值反馈。是序贯决策 + 评价式反馈。

### Q2（探索-利用）
**问**：agent 玩 10 个老虎机，前 100 步只拉它觉得最好的那一台，会怎样？

**答**：会卡在**次优策略**。前几次的奖励是随机采样，"觉得最好的那台"很可能只是运气好（小样本噪声），其实最优的那台还没被试到几次或者一上来就吃了几个差样本。完全不探索 = 把早期偶然的估计当真理，永远没机会纠正。这就是为什么需要 ε-greedy 等机制保留少量探索。

### Q3（反例辨析）
**问**：判断对错——"RL 是无监督学习的一种，因为它也不需要人工标签。"

**答**：**错**。
- 表面相似：两者都不要人工 label。
- 但**目标完全不同**：无监督学习目标是发现数据中的隐藏结构（聚类、降维、表示学习）；RL 的目标是最大化一个**奖励信号**。
- 而且 RL 的数据**不是给定的**，是 agent 通过自己的策略**与环境交互产生**的——策略一变，数据分布就变。这是 RL 独有的非平稳数据问题。
- 因此 RL 是与监督、无监督**并列**的第三种机器学习范式。

## 关键词速查（面试可能直接问）

- **agent / environment / state / action / reward**：五要素
- **policy π**：状态到动作的映射
- **return**：累积奖励
- **evaluative vs instructive feedback**：评价式 vs 指令式 → 区分 RL 与 SL
- **exploration–exploitation dilemma**：探索-利用困境
- **MDP**：马尔可夫决策过程（Ch 3 展开）
